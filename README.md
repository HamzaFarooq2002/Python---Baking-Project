# Python Banking Project

A simple command-line banking application built with Python.

## Features
- ✅ Check Balance
- ✅ Deposit Money
- ✅ Withdraw Money
- ✅ Input Validation

## How to Run
```bash
python banking.py
```

## Requirements
- Python 3.x

## Menu Options
1. Show Balance
2. Deposit
3. Withdraw
4. Exit
